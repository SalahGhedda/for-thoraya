# A little bouquet, for Thoraya

A hand-drawn bouquet that blooms petal by petal, followed by the animated dedication **“From Salah, to Thoraya.”**

**Website:** https://salahghedda.github.io/for-thoraya/

The illustration contains roses, peonies, a lily, tulips, hydrangeas, daisies, lavender, and foliage, gathered inside layered ivory and rose-colored wrapping with gold edging and a satin bow. The only visible text is the dedication, which appears after the drawing and color washes finish. Small icon buttons provide pause and replay. The page adapts to phone screens and respects reduced-motion preferences.

## Run locally

Open `index.html` in a browser. No installation or build is required; the artwork and fonts are included.

## Update the website

Edit `index.html`, `style.css`, or `bouquet.js`, then commit and push to `main`. GitHub Pages publishes the repository root automatically. `.nojekyll` keeps the site as plain static files.

The font licenses are included in `fonts/`.
